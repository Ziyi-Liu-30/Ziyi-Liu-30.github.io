# Ziyi Liu

Static academic homepage for GitHub Pages.

Live URL after Pages is enabled:

https://ziyi-liu-30.github.io/

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page content (bio, papers, grants, teaching, students) |
| `styles.css` | Layout and typography |
| `site.js` | Mobile menu |
| `portrait.jpg` | Faculty photo |

Edit `index.html` to update the page. No build step.

## Local preview

```bash
python3 -m http.server 43147
```

Then open http://localhost:43147 .
